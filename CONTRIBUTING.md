# Como contribuir

1. Abra ou escolha uma issue. Pra algo grande, discuta antes.
2. Crie uma branch: `feat/nome-curto`, `fix/nome-curto`, `docs/...`.
3. Use commits no padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/).
4. Abra um PR ligado à issue. O CI precisa passar.
5. Mudou arquitetura? Inclua um ADR em `docs/adr/`.

Ao contribuir, você concorda que seu código será licenciado sob GPL-3.0-or-later.
