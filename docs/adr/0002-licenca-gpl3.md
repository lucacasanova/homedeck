# ADR 0002 — Licença GPL-3.0

- **Status:** aceito
- **Data:** 2026-11-03

## Contexto
Queremos que melhorias voltem pra comunidade e que o projeto possa integrar o Sunshine (GPL-3.0).

## Decisão
Usar **GPL-3.0-or-later**.

## Consequências
- Forks distribuídos precisam continuar abertos.
- É possível embutir ou derivar do Sunshine e do Moonlight.
- Empresas que querem fechar o código não podem usar como base.
- Lojas: a App Store tem atritos históricos com GPL. Revisar antes da fase 6.
